# CODECHEF_PROJECT

## College Club Event Management Website

**CODECHEF_PROJECT** is a frontend-only college club event management website built using **React and Vite**. It allows students to explore upcoming club events, view event details, and register for events. It also provides a demo admin section for managing events and viewing student registrations.

> **Note:** This project does not use a backend or database. Application data is stored in the browser using `localStorage`.

## 🌐 Live Demo

[View the deployed project](https://codechef-project.vercel.app/)

## ✨ Features

### 🏠 Home Page

The home page contains:

- Hero section
- Club introduction/about section
- Featured event
- Upcoming events
- Navigation to other sections of the website

### 📅 Events Page

Students can:

- View available events
- Search for events
- Filter events by category
- Open event details
- Register for an event

### 📝 Event Registration

The registration form allows students to submit their information for an event.

The form includes validation to help ensure that the required information is entered correctly.
